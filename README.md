# UniLink 🎓 – University Student Networking and Engagement Platform

*UniLink* is a MERN-stack based platform built exclusively for university students to connect, collaborate, and grow academically and professionally within a verified ecosystem.

## 📌 Project Overview

Unlike global platforms like LinkedIn or Facebook, UniLink is focused on providing a *closed, university-centric network* that allows students to:
- Create personalized profiles
- Showcase verified skills and certificates
- Post and explore academic events
- Connect with peers through interaction and chat
- Generate engagement reports

## 🚀 Features

### 👤 Student Profile
- Upload profile picture, bio, skills, and achievements
- Add and request verification of skills & certificates

### 📬 Email & JWT Authentication
- Secure registration/login with email verification
- Protected routes using JSON Web Tokens

### 📣 Event Posting
- Share academic events, meetups, and opportunities
- Filter by category: hackathons, workshops, etc.

### 🗣 Real-Time Chat
- Direct messaging between users
- Private, secure conversations

### ✅ Admin Dashboard
- Review and verify user-submitted skills & certificates
- Moderate reported content
- Download user engagement reports

### 📊 Engagement Reports
- Auto-generate summary of posts, likes, comments, and connections
- Downloadable in PDF/CSV formats
